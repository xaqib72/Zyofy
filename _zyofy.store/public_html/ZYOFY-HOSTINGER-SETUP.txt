Zyofy Hostinger setup

1. Create a NEW empty MySQL database and database user in Hostinger.
2. Import zyofy_fresh_schema.sql into that database. It contains table structures only.
3. In config.php, set db.name, db.user and db.password to the new Hostinger values. Do not reuse the previous site's database or credentials.
4. Confirm app.url is correct for the domain being deployed. It currently points to https://testing.zyofy.store.
5. Set app.support_email to the mailbox the Zyofy owner will monitor.
6. Configure a new administrator through admin/setup-admin.php after the empty database is imported.

The former SQL export contained Amazon API credential material and has been replaced by a structure-only schema. Rotate the old Amazon API credentials before any future use.
